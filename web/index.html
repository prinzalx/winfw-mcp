    A deny always beats an allow, whatever the order of the list. Patterns accept the wildcards * and ?. A rule can be narrowed to one protocol, one direction, one port or port range such as 1024-2048 and one remote address or network such as 192.168.1.0/24; a rule that names none of them is about all of them. Every change is written to rules.toml and pushed to the store immediately. A detected application is one no rule speaks about yet; edit its path into a pattern such as C:\Program Files\*\app.exe before you allow or deny it, if you want to cover more than that one file.
