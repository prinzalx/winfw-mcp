# ADR 0000: Title of the decision

Write one file per decision. Name it `NNNN-short-title.md` and raise the number
by one each time. Copy this file, then fill it in.

## Status

Proposed, Accepted, or Superseded by 00nn.

## Context

The problem that forced a choice. Facts only.

## Decision

The choice, in one sentence. Use active voice.

## Consequences

What becomes easy, what becomes hard, and what we must do because of it.

## Alternatives

What we did not choose, and why.
